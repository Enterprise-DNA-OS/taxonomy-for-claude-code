# unrelate

Run `node scripts/taxonomy.mjs unrelate <relation-id> --note= --actor=` with the operator's actual values. Read the relevant scheme and term first. Use `--json` when composing a report.

This removes a relationship or label. Obtain explicit approval for the exact removal first. The audit record keeps the removed value.

Report the evidence from the command. Preserve URI identities. Never invent a translation or approval. A release is an internal snapshot, never a publication. Drafts stay in drafts and nothing sends.
