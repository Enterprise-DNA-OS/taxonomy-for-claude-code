# Why this desk has no editing screen

The working record is a vocabulary: stable term identities, labels, definitions, broader and related links, editorial requests and release decisions. An editor asks for a review or a change, and the command records the outcome.

PoolParty and the Graphwise platform offer considerably more: visual graph editing, semantic extraction, connected content systems and search applications. This desk does not recreate those services. Its scope is the internal terminology workflow you can inspect and change in your own database.

Read-only HTML shows the week, review queue and quality gaps. Documents produce a vocabulary register, an editorial review brief and a recorded release. None changes records. There is no mobile app, offline shared capture, drag-and-drop hierarchy, browser login, authenticated approval or shared portal. PGlite is for one local process; use a secured Postgres service for concurrent operators.

The agent recipes work with Claude Code, Codex, OpenCode or Cursor. No paid model API is required by the CLI. Your agent subscription, hosting, backup and operating costs remain yours. Enterprise DNA can build a web front end and agreed connections into your version, or install and operate it through Omni by Enterprise DNA.
